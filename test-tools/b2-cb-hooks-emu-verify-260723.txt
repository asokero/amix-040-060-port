What was implemented (commit follows this evidence)
---------------------------------------------------
1. cb_release040.s + patch_cb_release.py -- the copyback page-release barrier
   (CB-PAGE-LIFECYCLE-CLOSURE.md): cb_page_release = bounds-checked
   pp->pa conversion (pages/pages_base, /60, <<12) + 256x `cpushl dc` line
   loop; page_free hook @0xafb08 (displaced 40c346fc2400 -> bsr.l island;
   PC-relative on purpose -- no raw absolute detour) and free_vp_pages hook
   @0xafd98 (52b9+freemem reloc -> 4eb9 + reloc retargeted to the island,
   which replays freemem++).  Both hooks run before free-list publication,
   unconditionally (never skipped on p_mod).
2. hat040.s hat_unload(HAT_RELEPP) ordering fix (source, Lhl_dofree): leaf
   PTE clear + cpusha dc + pflusha now precede page_free (stock order freed
   the page with a live resident descriptor).
3. dma_cache040.s B2 protocol + patch_a3091_dma.py start retargets
   (A3091-B2-PREPARE-PATCH-SPEC.md): dma_a3091_startdma[_reconn] wrappers on
   the two arm relocations (0xd0b2 initial / 0xd21a reconnect; A2090/A2091
   startdma sites asserted untouched); single-segment ownership record
   (pa/len/dir/seq/state, PREPARED set before arm); PILOT prepare =
   `cpusha dc` (safe whole-cache push) + complete = per-range `cinvl` loop
   (FROM_DEVICE); the forbidden B1 completion-time `cinva dc` is GONE --
   image-wide census: exactly one cinva dc remains, the pre-enable pstart 'D'
   instance (safe: DC is off in that window).
4. patch_b2_flip.py -- produces the -b2 variants by flipping hat_cm_ram
   0x00 -> 0x20 (symbol-located, old-byte asserted); two artifact sets by
   design ("baseline smoke before the CM flip" on real HW).
