THE BOOT BLOCKER AND ITS FIX
----------------------------
The FPSP kernel first refused to boot with an AmigaOS "Software Failure" Guru,
Error D245 4C41 / Task 080D0040, 0 serial. That alert is NOT a crash: it is the
loader's own error macro, rel.c:53
    #define COMPLAIN(fmt,arg)  Alert(0x52454C41|AT_DeadEnd)
and 0x52454C41 = ASCII "RELA", | 0x80000000 (AT_DeadEnd) = 0xD2454C41 = the
displayed code. unix_boot was deliberately REJECTING the kernel.

Which check: relocsection() implemented ONLY R_68K_32 and COMPLAINed on any
other type. Reloc-type census:
    standard kernel : 29154 R_68K_32 (only)                  -> loads
    FPSP kernel     : 29796 R_68K_32 + 223 R_68K_PC16
                      + 106 R_68K_PC32 + 1 R_68K_PC8         -> rejected
All 330 PC-relative records come from fpsp040.o: the Motorola package must be
assembled with the GNU m68k toolchain (the CBM assembler rejects its syntax),
and GNU `ld -r` keeps cross-file bsr/bra/lea references as PC-relative
relocations. Our own hand-written .s overrides are unaffected (the M2 glue
object has R_68K_32 only).

FIX (f0ed373): rel.c now implements R_68K_PC32/PC16/PC8 as S + A - P with
P = relsechdr->sh_addr + r_offset (sh_addr is bound by bindsections, which runs
before relocsections). Out-of-range PC16/PC8 still COMPLAIN, so a truncation can
never be silent. Rebuilt with amiga-gcc per LOCAL-BUILD-NOTES §3.
Generalizes beyond FPSP: any GNU-assembled object can now be linked in.
