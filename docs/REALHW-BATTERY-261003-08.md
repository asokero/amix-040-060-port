**Why it was run.** The last image accepted on hardware is `260928-05`. Since then the base has
gained the D42 record's layout version 2 and the `edge_shared` move (`0556658`, `e953170`, both
2026-09-29), plus ISSUE-75 and ISSUE-76 today. This is the first image that carries all of them.

**Prediction, written before the boot:** `uname -m` reads `68060-261003-08`. All 40 magic words
read back. The battery passes 12/12, with `devmaptest` read separately because it can SKIP on a
card (ISSUE-57). The A3091 pilot's pairs are equal and every must-stay-zero counter reads zero.
`slbrk b` survives.

## Result — prediction met

```
=== MAGIC CHECK (40 blocks, 40 checks) ===
all 40 magics OK
BATTERY-RESULT PASS          (12 rows ok)
MUST-STAY-ZERO-OK
```

* `devmaptest` **measured** rather than skipped: `fails=0 skips=0`. It probed physical base
  `0x8000000`, and T1 and T2 both passed.
* The A3091 pilot's block (`DMA!`), read after the battery: `seq` 10899 = `prep_to` 7047 +
  `prep_from` 3852. The completes equal the prepares, and the four must-stay-zero fields are zero.
  Last segment `0x0ece2000`, in the Z3660's RAM.
* ISSUE-53 classifier: `a3w_eint_only` is still 0, with 47 000 level-2 interrupts seen, so it stays open.
  ISSUE-54 drain: never entered.
* ISSUE-75: `slbrk b /apps/midi/sernf` after the battery survived, and `0x40`–`0x7f` was
  unchanged.

## What this does not accept

* **The D42 service itself was not exercised.** `dma_prepare` and `dma_complete` are linked in
  this image, but nothing in it calls them: the A3091 pilot keeps its own record, and the
  service's caller is the driver line's A4091 driver. So the layout version 2 and `edge_shared`
  changes are carried, and this run says nothing about whether they are correct. The branch has
  not run.
* **ISSUE-76** cannot be exercised on this machine (no board with an id ≥ `0x8000`).

*Update 2026-10-04:* both of these now have hardware evidence from the driver line's rig (their
letter 15). For D42 version 2, see the evidence paragraph at the top of
`DMA040-SERVICE-RECORD.md`. For ISSUE-76, see its entry in `KNOWN-ISSUES.md`. Neither was
measured here.
* On this card, clean `FROM_DEVICE` counters show reach and self-consistency, not coherence. The
  Z3660 snoops Amiga-side DMA into its RAM (`DMA040-SERVICE-RECORD.md`).
